## Para qué usar Autores

En [Autores](/dashboard/autores) puedes consultar fichas existentes para comprobar nombres, variantes y obras ya analizadas de cada autor.

> [!IMPORTANT]
> En este módulo, el rol `editor` puede consultar, pero no puede crear ni editar autores.

Si tu obra asignada no trae ya declarada la autoría, puedes usar esta sección para evaluar mejor si el autor que necesitas está ya incluido.

## Flujo recomendado

1. Abre [Autores](/dashboard/autores).
2. Busca por nombre principal y por variantes.
3. Revisa la ficha y confirma que la coincidencia es correcta.
4. Vuelve a [Obras](/dashboard/obras?scope=mine) y aplica la atribución.

> [!WARNING]
> Si falta algún autor o detectas algún error, deja un comentario interno o escribe un correo.
