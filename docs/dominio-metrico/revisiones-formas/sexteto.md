# Sexteto

Estado: revisado con los datos del proyecto y bibliografía · 30 de julio de 2026

## Decisión

Una forma residual positiva, no una familia ni una configuración cerrada.

| Elemento | Valor |
| --- | --- |
| Forma | `sexteto` · estrofa residual |
| Configuración | `arte_mayor_consonante_variable` |
| Extensión | 6 versos |
| Medidas | arte mayor; normalmente 11 sílabas |
| Rima | consonante |
| Patrón de rima | variable y registrado en cada unidad |

Se elige `sexteto` cuando una estrofa satisface estos rasgos pero no corresponde a una
forma más precisa del catálogo. La condición residual evita que compita en el demarcador
con la sexta rima.

## Registrador

El recorrido de una unidad isométrica es:

```text
Sexteto → 11 sílabas → esquema observado → guardar
```

En una tirada, el rango debe ser múltiplo de seis. El editor responde en la primera
unidad y puede aplicar ambas respuestas a todas; solo cambia las unidades diferentes.

Se registran:

1. la medida o medidas de arte mayor presentes;
2. un esquema de seis posiciones, por ejemplo `AABCCB`.

El esquema es una respuesta abierta controlada: se eliminan los espacios, las letras se
normalizan a mayúsculas y la base exige exactamente una posición por verso. No se crea
un patrón nuevo en el catálogo por cada observación.

## Demarcador

El sexteto se ofrece como salida residual cuando quedan:

1. unidades de seis versos;
2. medidas de arte mayor;
3. rima consonante;
4. ausencia de una forma ordinaria más precisa.

La sexta rima `ABABCC` debe aparecer antes como candidata específica. El esquema concreto
del sexteto se registra después de identificar la categoría; no hace competir entre sí
una cantidad indeterminada de patrones.

## Relaciones

```text
Sexteto · residual
└── Sexta rima · subtipo_de Sexteto

Sexteto-lira · forma independiente
```

La sexta rima satisface la definición general del sexteto y fija una realización
endecasilábica `ABABCC`. El sexteto-lira no es subtipo del sexteto delimitado por el
proyecto porque combina arte mayor y menor.

No se crea una familia general de «estrofas de seis versos»: la extensión ya puede
consultarse como dato y no justifica por sí sola una familia ontológica.

## Fuente

José Domínguez Caparrós, *Métrica española*, Madrid, UNED, 2014, p. 198: llama sexteto
a la estrofa de seis versos de arte mayor o de arte mayor y menor combinados.

El proyecto aplica una delimitación más estricta, fijada por el IP para el corpus:
seis versos de arte mayor, normalmente endecasílabos, con rima consonante y disposición
variable. La fuente se conserva como contraste general y no sobrescribe ese criterio.

## Dudas para el IP

Ninguna imprescindible. Si el corpus documenta más adelante un sexteto mixto que no sea
sexteto-lira, deberá decidirse si se amplía esta configuración o se crea otra.
