# Instrucciones del repositorio

Lee [CLAUDE.md](./CLAUDE.md) antes de trabajar: contiene las reglas de arquitectura, base de
datos, validación y trabajo en main que también se aplican a los agentes Codex.

Lee y aplica [la guía de documentación](./docs/guia-documentacion.md) cuando crees, modifiques
o traslades documentación, datos de referencia o generadores. Actualiza la referencia vigente;
no crees un documento por sesión ni dupliques estados y pendientes.

Para el importador, empieza por [su índice](./docs/importador-metrico/README.md).
